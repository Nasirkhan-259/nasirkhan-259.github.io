IoT · ThingsBoard · Flutter · Web

IoT environmental monitoring

Problem

Live temperature, humidity, CO₂, PM2.5 and other indoor-air-quality readings need to become clear, manageable workflows across different customers and devices.

Approach

Structured ThingsBoard Cloud telemetry alongside web and mobile experiences for historical charts, configurable thresholds and role-aware device visibility.

Engineering work

Alert acknowledgement and snooze flows, notifications, reporting and API-driven interfaces designed to make operational follow-up straightforward.

Outcome

A focused monitoring foundation for turning device signals into usable information and actions. Client branding is intentionally not shown.

Technical stack: ThingsBoard Cloud, MQTT, HTTP, Flutter, web interfaces, PDF/CSV reporting

AI & MCP · Prototype / integration work

AI business-system integration

Problem

Assistants are only useful when they can operate within real business context without exposing broad or unsafe access to systems.

Approach

Exploration of Model Context Protocol connections between assistants, ThingsBoard, structured databases and external APIs.

Engineering work

Thinking through scoped tools, API boundaries, structured responses and operational workflows that keep the integration understandable and controllable.

Outcome

Practical prototype and integration work—not a claim of a launched AI SaaS or production RAG/agent product.

Technical stack: MCP, APIs, structured databases, ThingsBoard, tool access design

Backend & APIs · Confidential work

High-volume transaction and gaming backends

Problem

Transactional platforms need consistent handling of provider interactions, balances, bet/win/rollback flows and operations reporting—without losing track of edge cases.

Approach

Integration-oriented backend work focused on clear transaction paths, recovery-aware processing and operational visibility.

Engineering work

Provider API integrations, wallet and balance operations, bonus and tournament workflows, queues, currency/reporting logic and analytics dashboards.

Outcome

Robustness and integration design for confidential systems. No client names, endpoints, production figures or real player data are disclosed.

Technical stack: Laravel, Node.js, MongoDB, Redis, queues, operational analytics
